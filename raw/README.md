# raw/：原始資料（唯讀）

這個資料夾放網站內容的「依據」。`wiki/` 裡的每個數字、金額、距離、條號，都要能在這裡找到原文。

| 子資料夾 | 放什麼 | 檔名規則 | 例子 |
|---|---|---|---|
| `laws/` | 法規條文，逐字照抄 | `<法規代碼>.md`，法規代碼就是全國法規資料庫網址裡的 pcode | `D0120014.md`（災害防救法） |
| `web/` | 官方網頁、官方文件、新聞的重點摘錄 | `<發布者>-<主題>-<擷取日期>.md`，全部小寫英文、數字與連字號 | `ardswc-faq-20261114.md` |

## 每個檔案的寫法

1. 第一行是標題：`# 來源名稱（節錄）` 或 `# 來源名稱（重點摘錄）`。
2. 接著是「資料卡」表格，至少要有：類型、原始出處（網址）、擷取日期（YYYY-MM-DD）。法規另外寫最新異動日期與收錄條文。
3. 法規：一條一個 `## 第 N 條` 小標，條文逐字複製，不改字、不加註解。
4. 網頁：網頁原句寫成「原文：「……」」；自己整理的重點前面標「整理」，而且不能加入網頁沒有的內容。

## 規則

- AI 不可以改寫或刪除這裡的既有文字。只能新增檔案，或在法規檔尾追加新的條文。
- 新增或追加來源後，要在 `log.md` 記一筆。
- 網頁會改版：引用距擷取日期超過一年的網頁時，先重新查證，另存一份新日期的檔案。

完整規則見根目錄的 `AGENTS.md`。
